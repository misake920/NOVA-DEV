## Selecionar sem desperdício

Verificar primeiro stack/dependências existentes. Para necessidade específica, escolher poucas bases compatíveis, ler trecho relevante, dependências/licença e adaptar ao sistema visual. Não clonar repositórios completos quando bastar documentação ou componente.

Separar bibliotecas abertas de serviços/API, componentes ou assets com requisitos próprios de acesso. Não presumir acesso premium, preço zero ou licenciamento de imagens/modelos pela licença do código. Se 21st.dev não estiver disponível, usar base compatível ou composição autoral com os mesmos critérios de acabamento; não declarar instalação de componente não obtido.

Manter fontes como apoio técnico. Não impor paleta, tipografia, tema escuro ou arquitetura de exemplo sobre marca fornecida. Não tratar popularidade no GitHub como evidência suficiente de qualidade para o projeto.
